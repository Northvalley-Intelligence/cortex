Trace store

Every prompt and output is kept for full traceability, so the store grows over time. Pruning removes only finished traces (in-flight work is always kept) and reclaims disk on the database file. This does not touch the judgment cache. Irreversible.

Judgment cache

Deterministic relevance judgments are served from a prior run instead of re-calling the model. Clearing only forces those judgments to re-run next time — it costs a little latency, not data. This does not delete any traces. Irreversible.
